The six-screen flow

Click a screenshot to see the full screen.

    Permissions advance automatically once allowed. Downloads run during setup; Ready waits if they need more time.

    If setup needs attention

    These are states within the same flow. Customers return to the next step after resolving them.

    • Already allowed: permission screens confirm access and continue automatically.
    • Setup closed early: saved choices and downloaded files are reused on the next launch.
    • Setup cannot save: Ready stays open with a message. Try dictation can be retried.
    • Microphone access removed later: Linty asks for that permission again.
    • Unsupported speech build: setup explains which build is needed and keeps completion disabled.
    When someone changes a default

    Changing language or choosing another preset uses the same six screens. Custom shortcuts remain available in Shortcuts after setup.

    Copy audit: what became simpler
