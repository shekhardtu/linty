## What's new

- Improved pill reliability during repeated use by preventing automatic macOS window animations from exhausting background workers. Existing pill fades and reduced-motion support remain.
- Added local responsiveness diagnostics and safer repair of partially installed trigger-key monitors.
- Improved learning of short spelling corrections. Deleting a dictionary word now prevents automatic learning from adding it back unless you explicitly restore it.
- Added voice snippets: say a saved phrase to insert reusable text with its original formatting.
- Added writing styles for individual apps, with your default style used elsewhere.
- Added optional cursor-aware spacing and conservative sentence casing in supported prose apps.
- Added optional vocabulary hints from selected code in supported editors; hints stay temporary and do not become dictionary entries.
- Added an opt-in preview of selected-text voice editing, with review before applying and guarded Undo. Host-app Accessibility support determines availability.
