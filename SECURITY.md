# Security

Privacy first. Please use [GitHub's private vulnerability reporting](https://github.com/shekhardtu/linty/security/advisories/new) for security issues. Avoid posting exploitable details in a public issue before a fix is available.

Include the Linty version, macOS version, affected feature, steps to reproduce, and expected impact. Use a synthetic example where possible. Do not include API keys, signing credentials, or private recordings and transcription text.

Security fixes target the latest release. Install updates from [GitHub Releases](https://github.com/shekhardtu/linty/releases/latest) or Linty's updater.

Speech recognition and optional text cleanup run on the Mac. Audio, transcript history, and personal dictionaries stay on the device. Model downloads and app updates require internet access; dictation does not. See the [README](README.md#privacy-first) for details and implementation documentation.
